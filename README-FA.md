# اپ اندروید — فاز ۴

اپلیکیشن اندروید Kotlin + Jetpack Compose که به بک‌اند PHP (فازهای ۱ تا ۳) وصل می‌شود.

## راه‌اندازی بیلد خودکار در گیت‌هاب
۱. یک ریپازیتوری جدید در GitHub بسازید و کل این پوشه (`android/`) را در ریشه‌ی همان ریپو push کنید.
۲. به تب **Actions** بروید — با اولین push روی شاخه‌ی `main`، اکشن «Build Android APK» خودش اجرا می‌شود (چون نیازی به فایل‌های wrapper گریدل نیست؛ از `gradle/actions/setup-gradle` استفاده شده).
۳. بعد از پایان اجرا (چند دقیقه)، در همان صفحه‌ی اجرا، بخش **Artifacts** پایین صفحه یک فایل به اسم `tape-khash-app-debug` می‌بینید — دانلودش کنید، داخلش `app-debug.apk` است.
۴. این APK را روی گوشی اندرویدی نصب کنید (باید نصب از منابع ناشناس را برای مرورگر/فایل‌منیجر فعال کنید چون امضای رسمی گوگل‌پلی ندارد).

اگر بخواهید به‌جای دستی نصب‌کردن، بعداً APK امضاشده برای انتشار در بازارهای اندرویدی بسازید، باید یک keystore بسازید و signing config به `app/build.gradle.kts` اضافه کنید و رمزهایش را در GitHub Secrets بگذارید — این را می‌توانم در قدم بعدی برایتان اضافه کنم.

## تنظیم آدرس سرور
آدرس پیش‌فرض API داخل کد (`Session.kt`) است:
```
https://mahroch.ir/tape-khash-api/index.php
```
اگر پوشه‌ی بک‌اند روی هاست را اسم دیگری گذاشتید یا دامنه فرق دارد، در صفحه‌ی ورود اپ روی «تنظیمات آدرس سرور» بزنید و آدرس درست را وارد کنید — بدون نیاز به بیلد دوباره.

## ساختار
- `data/Session.kt` — نگهداری توکن ورود، remember-token و اطلاعات کاربر (SharedPreferences)
- `data/ApiClient.kt` — ارتباط با API (JSON + آپلود چندبخشی فایل)
- `ui/screens/LoginScreen.kt` — ورود (با «مرا به خاطر بسپار»)
- `ui/screens/AppSelectScreen.kt` — صفحه‌ی اول: انتخاب «مدیریت تپه‌ها» یا «مدیریت فاکتور خاش» بر اساس دسترسی کاربر
- `ui/screens/tape/` — جستجو، تپه‌های من، ثبت تپه (+ آپلود عکس از گالری)، و پنل مدیریت (کاربران، کاربران فعال، تاریخچه، ایمپورت اکسل، ویرایش هر تپه)
- `ui/screens/khash/` — نیروها، فاکتورها، پرداخت‌ها، سفارشات خاش (با مراحل تیک‌خور)، گزارش‌ها

## محدودیت‌های این نسخه (صادقانه بگویم چون نمی‌خواهم انتظار اشتباه ایجاد کنم)
- عکس فقط از **گالری** انتخاب می‌شود؛ گرفتن عکس مستقیم با دوربین در این نسخه نیست (اضافه‌کردنش ساده است، اگر بخواهید در قدم بعد اضافه می‌کنم).
- APK خروجی GitHub Actions **debug** و بدون امضای انتشار است — برای نصب دستی روی گوشی‌های خودتان کافی است، ولی برای انتشار در بازار اندرویدی نیاز به signing config دارد (بالا توضیح داده شد).
- چون من در این محیط به اینترنت دسترسی ندارم، این پروژه را نمی‌توانم واقعاً کامپایل/اجرا کنم؛ تک‌تک فایل‌ها را با دقت نوشتم و از نظر نحوی (تعداد پرانتز/آکولاد) بررسی کردم، ولی اولین بیلد واقعی در GitHub Actions انجام می‌شود. اگر خطای بیلدی داد، پیامش را برایم بفرستید تا سریع رفعش کنم.
